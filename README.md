## Hi, I'm Sriharsha 👋

Software engineer who likes building things that run on real hardware: desktop and TV apps, robots, sensors and
home-lab servers. I spent years building SharePoint and .NET solutions, and these days I mostly work on:

- 🤖 **AI agents:** building agents, tools and automations with LLMs
- 📱 **Native apps:** macOS (Swift) and Android TV (Kotlin)
- 🦾 **Robotics:** ROS 2, depth sensors and Kinect
- 🏠 **IoT & home lab:** embedded devices, Proxmox, Docker and self-hosted services

### 🚀 Featured projects

| Project | What it is | Stack |

| [**Pixlok**](https://github.com/SriharshaShesham/Pixlok) | Fast, native image viewer for macOS: flip through a folder, zoom, slideshow, quick edits, STL 3D models and video. Install with `brew install --cask SriharshaShesham/tap/pixlok`. | Swift, AppKit, SwiftUI |
